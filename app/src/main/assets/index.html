This calls your chosen AI provider directly from the browser using your own API key — no server involved. Anthropic supports this for prototyping via a direct-browser-access header; OpenAI and most others block direct browser calls (CORS) unless you're using a proxy — if a call fails with a network/CORS error, that's what happened, not a bug in this app.
